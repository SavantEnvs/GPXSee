# Seed provenance (`mayhem/<target>/testsuite/`)

GPXSee ships no sample data, so the seeds were made or taken from other projects' test data:

- Hand-written text samples: `data-gpx`, `data-nmea`, `data-kml`, `data-geojson`, `data-igc`, `data-any`
  (TCX, CSV, CUP, LOC, OziExplorer PLT/WPT/RTE, ITN, SRT, TwoNav TRK, GPSDump WPT, all renamed `.bin`).
- Generated by small Python writers following GPXSee's own parsers: `data-fit`, `data-vtk`,
  `data-exif` (JPEG + EXIF GPS IFD), `data-gpi`, `data-mp4` (udta `©xyz`, GoPro GPMF), `data-ghp` (OnMove 20-byte GHP records), `map-rmap`,
  `map-jnx`, `map-qct`, `map-aqm` (AlpineQuest FLATPACK1), `map-gemf`, `map-tar` (TrekBuddy tar: OziExplorer
  `.map` + `set/` PNG tiles), `map-kmz` (`doc.kml` GroundOverlays + PNGs, stored and deflated) and
  `map-ozf` (OZF2 and XOR-keyed OZF3 images, two zoom levels of zlib-packed 64x64 tiles; the harness
  supplies the OziExplorer `.map` that names them, `writeOziMap` in `mayhem/fuzz/exercise.h`).
- `map-img`: built with mkgmap (r4924) from a tiny hand-written OSM file.
- `map-bsb`, `map-geotiff`, `map-enc`, `map-pmtiles`: GDAL autotest data
  (https://github.com/OSGeo/gdal/tree/master/autotest, MIT licence).
- `map-mapsforge`: mapsforge map-reader test resources
  (https://github.com/mapsforge/mapsforge/tree/master/mapsforge-map-reader/src/test/resources, LGPL-3.0).

`mayhem/test/expected.txt` holds what GPXSee parses/draws from each of these files (see `mayhem/test.sh`).
